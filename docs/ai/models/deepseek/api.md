# DeepSeek API

OpenAI-compatible and Anthropic-compatible endpoints.

| | Value |
| --- | --- |
| OpenAI base URL | `https://api.deepseek.com` |
| Anthropic base URL | `https://api.deepseek.com/anthropic` |
| Current models | `deepseek-flash`, `deepseek-v4-pro` |

List models: `GET /models`. Pricing and feature matrix: Models & Pricing page (peak/off-peak, cache hit/miss).

## Legacy aliases (archive)

`deepseek-chat` and `deepseek-reasoner` were scheduled for full retirement after **24 Jul 2026 15:59 UTC** (V4 Preview notes / changelog). During transition they routed to V4-Flash non-thinking / thinking. Do not treat them as current product names on the lab index.
