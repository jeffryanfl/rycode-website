# Muse Wonder

Muse Wonder is Meta Superintelligence Labs series, called by Meta its "most capable models to date", released **12 Oct 2026**. Two sizes: **Muse Wonder** (`muse-wonder-1.0`, Meta Model API and Muse Code) and **Muse Wonder Full** (Muse Code subscribers only, no API). Meta offers them through its API and plans. Meta says Wonder will soon power the Muse app, subscribers first.

## Training

Builds on Muse Spark, with more pretraining and reinforcement learning (Meta). Trained at Meta’s gigawatt-scale Prometheus data center (Meta). Parameters, architecture, data mix: **UNKNOWN**.
