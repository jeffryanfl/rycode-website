# Muse

Muse is Meta’s model family from Meta Superintelligence Labs. It is separate from Llama. Muse Wonder (12 Oct 2026) is what Meta calls its most capable model to date, with a larger Muse Wonder Full in Muse Code only. Muse Spark is the lighter closed / API multimodal reasoning line that powers Meta AI. Muse Glimmer is the open-weight sibling distilled from Spark. Muse Image and Muse Video are media models. Muse Code is a multi-agent coding product that runs Wonder and Wonder Full.
