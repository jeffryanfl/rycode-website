# Muse

Muse is Meta’s model family from Meta Superintelligence Labs. It is separate from Llama. Muse Spark is the closed / API multimodal reasoning line that powers Meta AI. Muse Glimmer is the open-weight sibling distilled from Spark. Muse Image and Muse Video are media models. Muse Code is a multi-agent coding product built around Spark.
